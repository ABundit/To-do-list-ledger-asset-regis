# BaanBalance

Mockup dashboard ภาษาไทยสำหรับจัดการชีวิตและการเงินของครอบครัวในที่เดียว รองรับการสลับโหมด Personal/Work พร้อมแนวคิดสำหรับ:

- รายการสิ่งที่ต้องทำ
- บันทึกรายรับ–รายจ่ายจากเงินเดือน บำนาญ ปันผล ดอกเบี้ย และแหล่งอื่น
- ภาพรวมการลงทุนหลายประเภท
- ทะเบียนทรัพย์สินและเอกสารประกอบ PDF/JPG/PNG
- การเลือกดูข้อมูลแยกตามสมาชิกครอบครัว

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

## ตรวจสอบโปรเจกต์

```bash
npm run lint
npm run build
```
